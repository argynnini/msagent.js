特長

キャラクターファイルを読み込むだけで、ページの上にキャラクターが住みつきます。

🎞️

本物のアニメーション

.acs も .act もブラウザ内で解析して canvas に描画。分岐・終了分岐・戻りアニメ・効果音まで再生します。

🗣️

しゃべって口パク

吹き出しと一緒に Web Speech API で読み上げ、キャラクターの口の画像を切り替えて口を動かします。

📎

clippy.js と同じ API

clippy を msagent に書き換えるだけ。play・speak・moveTo・gestureAt は順番待ちで 1 つずつ実行します。

📦

依存なし・軽量

jQuery も変換ツールも要りません。ESM と <script> 用の両方を用意し、型定義付きです。

使い方

キャラクターファイルを置いて、msagent.load() で呼び出します。

import msagent from "msagent.js";

msagent.BASE_PATH = "/agents/";

msagent.load("Merlin", (agent) => {   // → /agents/Merlin.acs
  agent.show();
  agent.speak("こんにちは！");
  agent.play("Congratulate");
  agent.moveTo(100, 100);
  agent.gestureAt(0, 0);
});
  • show() / hide()登場・退場
  • play(name, timeout, cb)アニメーションを再生
  • animate()待機動作以外から 1 つ選んで再生
  • speak(text, hold)吹き出しでしゃべる (読み上げ + 口パク)
  • moveTo(x, y, duration)移動前の動き → 移動 → 移動後の動き
  • gestureAt(x, y)指した姿勢を、次の動きまで保つ
  • stop() / stopCurrent()順番待ちを捨てる / いまの動きを終わらせる
  • delay(ms) / pause() / resume()待つ・一時停止・再開
.acs / .act ファイルについて: キャラクターは Microsoft などのもので再配布できないため、同梱していません。 .acs は Office 2000 / XP / 2003 に、.act は Office 97 に付属していたものか、Agentpedia などから入手してください。
